# EREBOS — 잊힌 성소

HTML + CSS + JS + Canvas로 만든 1스테이지 메트로베니아 (외부 엔진 없음).

🎮 **플레이:** https://cardanoian.github.io/erebos/ (배포 후 갱신)

## 조작

| 키      | 동작                                                                    |
| ------- | ----------------------------------------------------------------------- |
| ←→ / AD | 이동                                                                    |
| Z       | 점프 (벽에서 벽점프)                                                    |
| X       | 대시                                                                    |
| C       | 공격 (3단 콤보)                                                         |
| V       | 조사                                                                    |
| Esc / M | 일시정지 / 음소거                                                       |
| 모바일  | 좌측 가상 스틱 이동, JUMP/DASH/ATK/E 버튼, II 일시정지 (가로 모드 권장) |

## 게임 구성

- 4구역 탐색 + 대시·벽점프 해금 + 정식보스 (타락한 종지기 2페이즈)
- 플레이타임 10~15분, 종 세이브, 클리어 기록 저장

itch.io 무료 에셋 사용. 상세 라이선스는 [CREDITS.md](CREDITS.md) 참고.
